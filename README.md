# AI/ML Internship Task 1 – Titanic Dataset Data Preprocessing

## Project Description
This project focuses on preprocessing the Titanic dataset using Python and Pandas.

## Tasks Performed
- Loaded the Titanic dataset
- Checked and handled missing values
- Encoded categorical data
- Standardized numerical features
- Detected and removed outliers
- Saved the cleaned dataset

## Dataset
The original Titanic dataset is included as:
- `Titanic-Dataset.csv`

The cleaned dataset is saved as:
- `cleaned_titanic.csv`

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Files
- `task1.py` – Python preprocessing code
- `Titanic-Dataset.csv` – Original dataset
- `cleaned_titanic.csv` – Cleaned dataset

## Result
The original dataset contained **891 rows and 13 columns**.  
After removing outliers, the dataset contained **577 rows and 13 columns**.
